Graph-based Method for Process-based Fraud Detection and its Integration with COBIT 2019 APO12 Risk Capability Assessment

Process-based fraud (PBF) threatens organizational integrity when real operations deviate from Standard Operating Procedures (SOP). This study proposes a graph-based detection framework that integrates graph similarity analysis and rule-based constraints to identify six PBF categories: skipped activity, wrong pattern, wrong decision, wrong resource, wrong duty, and wrong throughput time. Using a synthetic event log from the Accounts Receivable and Reminder SOP of a tourism enterprise in Bali, the method achieved high F1-scores (≥0.95) for structural and role-based anomalies and moderate performance for time deviations (F1 ≈ 0.65). The detection outcomes were further mapped to COBIT 2019’s APO12 domain, producing quantitative indicators—APO12.01 (2.9%), APO12.02 (1 case), and APO12.03 (100%)—that support risk capability evaluation. The results demonstrate the framework’s effectiveness in detecting process-level anomalies and translating them into measurable governance insights.
